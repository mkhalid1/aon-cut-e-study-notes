# Sources

Every fact in these notes about the tests themselves comes from Aon. Each source below was checked live on 24 November 2026. If something has changed, please [open an issue](https://github.com/mkhalid1/aon-cut-e-study-notes/issues).

## Publisher: Aon

| Source | Used for |
|---|---|
| [Prepare for your Online Assessment (Aon)](https://www.aon.com/en/capabilities/talent-and-rewards/prepare-for-your-online-assessment) | Test names and the official length of each test: scales numerical 12 minutes and 37 tasks, scales verbal 12 minutes and 49 tasks, scales ix 5 minutes and 20 tasks, plus the other Aon tests listed in [Other Aon tests](other-aon-tests.md). Also: how a test is structured (untimed instructions and examples, then the timed test), that a started test cannot be paused, that most single tests last under fifteen minutes, that most processes have no more than five tests, that you usually get several days, that a calculator or pen and paper can help, that points are usually added for correct answers and deducted for incorrect ones, that retests can follow at interview, feedback reports, adjustments, and data retention. |
| [Practice Tasks: Numerical Reasoning (Aon, PDF)](https://assets.aon.com/-/media/files/aon/capabilities/talent-and-rewards/practice-tasks---numerical-reasoning.pdf) | How scales numerical works: several data sheets, statements answered TRUE, FALSE or CANNOT SAY, one correct answer, each statement relates to only one data sheet, the sheets do not change during the test, have a pen, paper and calculator ready, you are not expected to finish. Aon's worked rationale also shows that units matter and that a figure close to the true value is still false when the statement is not an approximation. |
| [Practice Tasks: Verbal Reasoning (Aon, PDF)](https://assets.aon.com/-/media/files/aon/capabilities/talent-and-rewards/practice-tasks---verbal-reasoning.pdf) | How scales verbal works: several data sheets of text, statements answered TRUE, FALSE or CANNOT SAY, each statement relates to only one sheet. Aon's rationale shows that a statement with the same meaning in different words is TRUE, and that a cause the text does not state is CANNOT SAY. |
| [Practice Tasks: scales ix (Aon, PDF)](https://assets.aon.com/-/media/files/aon/capabilities/talent-and-rewards/practice-tasks--inductive-reasoning-ix.pdf) | How scales ix works: an image of 9 objects, all following one rule except one, 20 items per administration in increasing difficulty, one correct answer. Aon's examples include rules about rotation, repeating patterns, alternating colours, a shape sitting fully inside another, and a shared number of sides. |
| [Aon acquires cut-e, press release of 4 May 2017 (Aon newsroom)](https://www.mynewsdesk.com/dk/aondk/pressreleases/aon-acquires-leading-provider-of-talent-measurement-and-psychometric-assessment-1947688) | Aon bought cut-e, based in Hamburg and founded in 2002. Why the tests are called both "cut-e" and "Aon". |

None of Aon's practice questions or data sheets appear in these notes. We use the PDFs only for the rules of each test, which we describe in our own words.

## What Aon does not publish

We looked for these and did not find them on Aon's own pages, so the notes do not give numbers for them:

- a pass mark or cut-off score for any scales test
- the size of the deduction for a wrong answer
- which norm group an employer compares you with
- an official list of employers that use each test
- whether you can retake a test after a set period

## What is our own guidance

Methods, traps, timing advice, study plans and all practice items are our own. They follow the rules Aon describes, but they are not Aon's advice and not Aon's material. Where a page gives a time per item, it is simple arithmetic on Aon's published length and count.
